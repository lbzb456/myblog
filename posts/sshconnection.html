本文介绍如何通过 SSH 连接到 RK3588 控制板，包括网络配置、SSH 工具使用、文件传输等关键步骤，适用于无人船、机器人等嵌入式开发场景。

一、准备工作

在开始之前，请确保已完成以下准备工作：

  • RK3588 控制板已通电并启动
  • 控制板与电脑处于同一局域网内（或通过网线直连）
  • 已获取控制板的 IP 地址
  • 电脑已安装 SSH 客户端工具

二、RK3588 控制板简介

RK3588 是瑞芯微（Rockchip）推出的一款高性能 8 核 ARM 处理器，广泛应用于嵌入式开发、边缘计算、人工智能等领域。在无人船、机器人等场景中，常作为主控板使用。

控制板接口丰富，支持多种外设扩展。

三、使用 SSH 连接 RK3588

1. 网络连接确认

首先确认电脑与 RK3588 控制板的网络连接是否正常：

# Windows / Linux / macOS 通用命令
ping <RK3588_IP地址>

# 例如：
ping 192.168.1.100

如果能看到回复数据，说明网络连接正常。

2. SSH 命令行连接

使用系统自带的 SSH 命令连接：

# 默认用户名通常为 root 或 ubuntu
ssh <用户名>@<RK3588_IP地址>

# 例如：
ssh root@192.168.1.100

首次连接会提示是否信任该主机，输入 yes 并回车，然后输入密码即可登录。

3. 推荐工具：MobaXterm

对于 Windows 用户，推荐使用 MobaXterm 这款强大的远程连接工具，它集成了 SSH、SFTP、X11 转发等功能。

也可使用NoMachine进行局域网带界面的远程。

下载 deb 格式（注：MobaXterm 实际为 Windows 工具，此处下载页面提供不同版本）的安装包。

MobaXterm 主要功能：

功能说明
SSH 会话远程终端连接
SFTP 文件传输图形化文件管理，方便上传下载
X11 转发在 Windows 上显示 Linux 图形界面程序
多标签管理同时管理多个会话
内置文本编辑器直接编辑远程文件

四、文件传输

通过 MobaXterm 可以方便地进行文件传输：

  1. 建立 SSH 连接：打开 MobaXterm，新建 Session，选择 SSH，输入 RK3588 的 IP 地址、用户名和密码
  2. 使用 SFTP：连接成功后，左侧会自动显示文件管理器面板
  3. 拖拽传输：直接将文件从 Windows 资源管理器拖到左侧面板，即可上传到 RK3588 控制板

常用文件传输命令（可选）

如果使用命令行，可以通过 scp 进行文件传输：

# 从电脑上传文件到 RK3588
scp <本地文件路径> <用户名>@<RK3588_IP>:<目标路径>

# 示例：传输 deb 安装包
scp vscode.deb root@192.168.1.100:/home/root/

# 从 RK3588 下载文件到电脑
scp <用户名>@<RK3588_IP>:<远程文件路径> <本地路径>

五、常见问题与解决方案

问题解决方案
连接超时检查网络连接、IP 地址是否正确、防火墙是否放行 22 端口
权限拒绝（Permission denied）核对用户名和密码，确认 SSH 服务已启动：sudo systemctl status sshd
无法上传文件检查目标目录的写入权限，必要时使用chmod 修改权限
中文文件名乱码在 MobaXterm 中设置字符集为 UTF-8

六、安全建议

为了保证 RK3588 控制板的安全，建议：

  1. 修改默认密码：首次登录后立即修改默认密码

    passwd

  2. 禁用 root 远程登录（可选）：编辑 /etc/ssh/sshd_config，将 PermitRootLogin 改为 no

  3. 使用密钥登录：生成 SSH 密钥对，配置免密登录，提高安全性

  4. 更改默认 SSH 端口：将默认的 22 端口改为其他端口，减少扫描攻击

七、总结

本文介绍了 SSH 连接 RK3588 控制板的完整流程，包括：

  1. 网络准备：确保电脑与控制板网络互通
  2. SSH 工具：推荐使用 MobaXterm，集成度高、功能强大
  3. 文件传输：通过 SFTP 或 scp 命令传输文件
  4. 安全配置：修改密码、使用密钥等安全措施

通过 SSH 远程连接 RK3588 控制板，可以方便地进行无人船、机器人等嵌入式项目的开发与调试。
